## 🎮 快速开始

1.双击exe打开，查看引导
<div align="center">
<img width="442" height="319" alt="1 1" src="https://github.com/user-attachments/assets/9054aff3-65e6-44f3-bd72-4133907ee70c" />
</div>

2.进入游戏编队界面，然后在操作录制界面配置好对应初始干员数量和初始道具数量。以下示例中初始干员数量为4(包括助战)，未启用助战，因此不勾选助战。
实际进入游戏后有2种初始道具，因此数量为2。
<div align="center">
<img width="640" height="400" alt="2 1" src="https://github.com/user-attachments/assets/10817889-8cf7-4847-a339-a144963c5b32" />
<img width="609" height="400" alt="2 2" src="https://github.com/user-attachments/assets/45112424-12e7-4743-9939-74c7c071d4a7" />
</div>

3.左上角悬浮窗初次加载OCR可能较慢，当显示识别完成，可以进入游戏后，正常点击开始作战即可。
<div align="center">
<img width="480" height="210" alt="3 1" src="https://github.com/user-attachments/assets/b040c7b4-f6ae-4864-b294-993a5f2fc76f" />
</div>

4.即使只打了一个开头，也可以点击结束录制，悬浮窗会显示脚本保存位置。
<div align="center">
<img width="640" height="400" alt="3 2" src="https://github.com/user-attachments/assets/e730289d-792b-42f5-982a-e887f453623a" />
</div>

5.如果你认为这个轴值得继续打下，点击装载脚本，选择刚才保存的脚本，回到编队界面，再次点击开始录制。这次你<span style="color:red">不需要再点击开始作战</span>。
如果你认为这个轴不值得继续打下去，或者还需要继续探索，跳转至步骤8。
<div align="center">
<img width="609" height="400" alt="4 1" src="https://github.com/user-attachments/assets/eb83596b-6441-49ed-a98f-4da77c74ac96" />
<img width="640" height="400" alt="4 2" src="https://github.com/user-attachments/assets/adc54fc0-d82d-42fb-970d-8b1b903d8b08" />
</div>

6.脚本会自动点击并开始作战，执行完你刚才打了的轴，会自动暂停，期间你可以提前接管，也可以暂停后正常继续游戏，录制会正常进行。
<div align="center">
<img width="640" height="400" alt="4 3" src="https://github.com/user-attachments/assets/43c3bbf1-f8db-4b45-b954-ea0a08444a5b" />
</div>

7.又打完了一把，再次点击结束录制，这次你的轴也会保存，回到步骤5。
<div align="center">
<img width="640" height="400" alt="4 4" src="https://github.com/user-attachments/assets/18068aa4-1ae7-4986-9f28-90686ad349f2" />
</div>

8.如果你认为这个轴没什么潜力，或者需要继续探索，你可以不装载脚本，或者清楚已装载的脚本，直接点击开始录制，并进入游戏录制下一把轴即可，就像步骤3那样。

**总体而言，你不再需要进行重复性工作，你的每一场游戏的轴，都会被保存下来，你可以在任何时候由脚本完成你的任何一场游戏的轴，或是完整的，或者接着续打。录制有时候可能会漏掉或错误识别操作，如果发现脚本执行存在问题或偏差，打开脚本编辑进行修改。**
